AI-2 PROMPT ENGINEERING — EXPERIMENT 3: STRUCTURED OUTPUT (JSON)

- name: string
- date: string in YYYY-MM-DD format
- amount: number

Rules:
- Do not include Markdown code fences.
- If a field is missing, use null.
- Amount must be numeric without currency symbols.
- Do not add any other keys.

ACTUAL OUTPUT: {"name": "Priya", "date": "2026-11-12", "amount": 450}

All five had correct names, dates, numeric amounts, valid JSON syntax, and required fields.
